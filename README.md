## ISD · Segundo parcial: Calculadora de subneteo IPv4
Carpeta: `ISD/SegundoParcial/Subneteo`
Página: https://kiroshisjj.github.io/2026-PS-ISD-SerranoJimenezKiroshi/ISD/SegundoParcial/Subneteo/

- **Decimal a binario**: método de restas (128, 64, 32...).
- **FLSM**: subredes iguales, por número de subredes o por hosts.
- **VLSM**: cada área recibe el bloque más chico que le alcanza (de mayor a menor).
- **¿A qué red pertenece?**: red, primer/último host y broadcast (IP AND máscara).
